## Bot media assets

### `/start` banner

To clone the client’s reference bot UI, place a banner image at:

- `assets/start_banner.png`

Recommendations:

- Wide aspect ratio (around 3:1).
- Keep important content centered (Telegram crops on some clients).
- Avoid tiny text; it should be readable on mobile.

This file is intentionally **not** committed automatically because it may contain client branding.
